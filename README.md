# PhoneMic

Use your Android phone as a wireless microphone for your Windows PC over Wi-Fi.

**Website and downloads:** https://amalthilakan.github.io/phonemic/

- `PhoneMic.exe` - Windows app (Windows 10/11, 64-bit). Needs the free [VB-Audio Virtual Cable](https://vb-audio.com/Cable/).
- `PhoneMic.apk` - Android app (Android 7+).
- `PhoneMic-Source.zip` - source code (Windows app in Go, Android app in Java).
